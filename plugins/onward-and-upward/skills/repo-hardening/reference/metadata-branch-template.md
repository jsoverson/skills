# Metadata on branches Github action

A template github action for storing metadata on git branches.

## Github action YAML

```yaml
name: 'Store File to Isolated Branch'
description: 'Saves a metadata file to an orphan git branch to keep history clean.'

inputs:
  source-file:
    description: 'The path to the file generated by your test or build step'
    required: true
  target-branch:
    description: 'The branch where you want to store this file'
    required: false
    default: 'coverage-data'
  target-filename:
    description: 'What to name the file inside the target branch'
    required: false
    default: 'coverage-summary.json'

runs:
  using: 'composite'
  steps:
    - name: Commit and Push File to Branch
      shell: bash
      run: |
        # Configure Git Bot
        git config --global user.name "github-actions[bot]"
        git config --global user.email "github-actions[bot]@users.noreply.github.com"

        # Stash the file safely outside the working directory
        cp "${{ inputs.source-file }}" /tmp/isolated-metadata-file

        # Fetch and manage the target branch
        git fetch origin
        if git show-ref --verify --quiet "refs/remotes/origin/${{ inputs.target-branch }}"; then
          git checkout "${{ inputs.target-branch }}"
          git pull origin "${{ inputs.target-branch }}"
        else
          echo "Branch ${{ inputs.target-branch }} does not exist. Creating orphan branch..."
          git checkout --orphan "${{ inputs.target-branch }}"
          git rm -rf . # Wipe the working directory clean for the new branch
        fi

        # Place the file, commit, and push
        cp /tmp/isolated-metadata-file "./${{ inputs.target-filename }}"
        git add "${{ inputs.target-filename }}"
        git commit -m "Automated update: ${{ inputs.target-filename }} (${GITHUB_SHA::7})" --allow-empty
        git push origin "${{ inputs.target-branch }}"
```

Use it in your workflow like this:

```yaml
name: CI Pipeline

on:
  push:
    branches: [ main ]

jobs:
  test-and-track:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Run Python Tests
        run: |
          pip install pytest pytest-cov
          pytest --cov --cov-report=json # Generates coverage.json

      # --- CALLING YOUR REUSABLE ACTION HERE ---
      - name: Archive Coverage Metrics
        uses: ./.github/actions/store-file-to-branch
        with:
          source-file: 'coverage.json'
          target-branch: '/etc/coverage'
          target-filename: 'latest-coverage.json'
```
