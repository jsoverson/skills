description: "What do you want from me?"
disable-model-invocation: true
---

The user doesn't know what they're being asked. Re-state the request clearly. Keep information, drop filler words like adjectives, adverbs, and unnecessary phrases.

1) If they need to know something, state clearly what they need to know.
2) If they need to act, succintly state what they need to do.
3) If they need to provide answers, re-state the questions succinctly. Include recommendations if relevant.
